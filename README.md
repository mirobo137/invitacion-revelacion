# Una sorpresa está en camino

Invitación interactiva para la revelación de sexo del bebé en Mexicali.

## Vista previa

La versión publicada en GitHub Pages es una muestra estática para revisar el diseño. La predicción de cada invitado se guarda solo en su propio navegador; los resultados no se comparten entre teléfonos.

## Ejecutar en local

```sh
npm install
npm run dev
```

Para generar la versión estática que publica GitHub Pages:

```sh
npm run build:pages
```

GitHub Actions vuelve a generar y publicar la invitación cada vez que se actualiza la rama `main`.
